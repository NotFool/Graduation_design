

涉及漏洞触发的关键变量为：

**_gap**  
**gap**  
**start**  

关键触发路径分析：  
1. `_gap = ~0`（32位系统下值为0xFFFFFFFF，即4294967295）  
2. `gap = _gap / 8`（计算结果为536870911，掩盖了后续运算的溢出风险）  
3. `thread_func(start, start + gap, fd)`（若函数内部存在基于`start + gap`的乘法运算，例如 `size = (end - start) * elem_size`，当`elem_size ≥8`时触发整数溢出）  

漏洞本质：通过`_gap/8`的截断操作绕过显式的大数限制，使后续运算（如内存分配）因整数溢出导致缓冲区越界。
